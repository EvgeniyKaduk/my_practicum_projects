# Прогноз оттока клиентов
## Описание проекта
Компания *** – крупнейший поставщик материалов и оборудования для широкоформатной печати, производства наружной, интерьерной и транзитной рекламы, сувенирной продукции, оформления торговых и общественных пространств, детейлинга и решений из инженерных пластиков.
●	Необходимо разработать систему автоматической разметки текстов телефонных разговоров – кластеризация звонков по тегам
●	Создать модуль для интеграции в систему заказчика
●	Подготовить документацию как подключить и использовать модуль

## Описание данных
Заказчик предоставляет:
●	расшифровки телефонных разговоров
●	образец разметки для обучения модели
 ○	ручная разметка
 ○	полуавтоматическая
●	список тегов
●	списки брендов, материалов, сотрудников, конкурентов

## Используемые библиотеки
*pandas*, *numpy*, *re*, *scikit-learn*, *lightgbm*, *transliterate*, *flashtext*, *pymorphy3*, *gensim*, *lightgbm*, *functools*, *streamlit*

## Результат
●	Решение подбирает список подходящих тегов для текста диалога
●	При выявлении в разговоре тематик
 ○	“Консультация по материалу”,
 ○	“Консультация по бренду”,
 ○	“Конкуренты”,
 ○	“Фамилии сотрудников”,
моделью используются дополнительные списки брендов, материалов, конкурентов и сотрудников и выдаются найденные наименования с вероятностью

Реализовано приложение на базе streamlit, в котором можно вводить отлельные тексты (за один звонок), либо загружать *.csv файл с текстами.

Метрика F-beta score macro для beta=0.5 по основным тегам даёт значение 0.58 на тестовой выборке,  по тегам-брендам 0.56, по тегам-фамилиям 0.66.

## Как запустить проект
1. Требования
- Перед запуском убедитесь, что у вас установлено: Python 3.10 или выше; Git (если вы клонируете проект с GitHub); pip (менеджер пакетов Python).
- Проверить это можно в терминале:
 - python --version
 - pip --version
 - git --version 

2. Клонирование проекта
git clone https://github.com/EvgeniyKaduk.git

3. Запуск из каталога проекта
cd call-tagger

4. Установка и активация виртуального окружения
- python -m venv venv
- Активация окружения в Windows: venv\Scripts\activate
- Активация окружения в macOS/Linux: source venv/bin/activate

5. Установка зависимостей
- pip install -r requirements.txt
- Если вдруг появится ошибка с зависимостями, можно обновить проблемную библиотеку: pip install --upgrade pip <имя_библиотеки>

6. Проверка структуры проекта

project/
├── app.py
├── call_tagger.py
├── requirements.txt
├── data/
│   └── entity_dict.json
├── models/
│   ├── model_main.pkl
│   ├── model_brand.pkl
│   ├── model_employee.pkl
|   ├── mlb_main.pkl
|   ├── mlb_brand.pkl
|   └── mlb_employee.pkl

7. Запуск приложения в Streamlit
- streamlit run app.py
- Перейти по ссылке в консоли: Local URL: http://localhost:8501 (либо автоматически запустится в браузере)
